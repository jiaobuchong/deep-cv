The linear-probe head has already fit the training set

Weak signal. It was trained on frozen features of the same training images, so the first training loss is low (2.29 vs 4.39 with prototypes, LoRA) and little gradient reaches the backbone.

Then a mismatch. Once the features move, the fitted head no longer fits: with LoRA the training loss rose from 2.22 to 2.69 in epoch 1.

Prototypes generalize. Higher training loss (1.85 vs 1.77), yet +3.1 points on CodaBench.

Why does the stronger start lose? Our explanation, consistent with the logs: the linear-probe head was trained on frozen features of the very same training images, so it already fits the training set. The training loss starts low, 2.29 against 4.39 for the prototype head in the LoRA runs, so only a weak gradient reaches the backbone and it learns less. Then, as soon as the backbone features move, the fitted head no longer matches them. With LoRA the training loss actually rose from 2.22 to 2.69 during the first epoch, and the holdout accuracy stalled. The chart shows full fine-tuning on all data. The prototype run keeps a higher training loss all the way, 1.85 against 1.77 in the last epoch, but it is 3.1 points better on CodaBench, so the linear-probe run is fitting the training images rather than learning general features. The step at every epoch boundary is the same memorization effect.
