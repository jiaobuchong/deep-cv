The second question: how should the parameter-efficient model spend its budget? All runs here use the same linear-probe head and 3 epochs, so only the PEFT design changes. Halving the LoRA learning rate did nothing: minus 0.12, which is within noise. Putting LoRA on every linear layer, so that it also adapts the MLP, gained 0.88 points, at 1.375% of the backbone, still far below the 5% limit. So the bottleneck is capacity, not the learning rate. AdaptFormer, the adapter in parallel to the MLP, is close in accuracy and the fastest to train, but its modules cannot be merged into the backbone, so inference at batch size 1 is about 35% slower than a merged LoRA.
